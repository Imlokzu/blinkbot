# Bundled chat wallpapers

These files are downloaded stock assets, reviewed on 2026-10-03. They are
bundled locally so dashboard rendering does not contact the stock providers.
The existing owner-provided `../chat-reference-sky.jpg` is a separate asset.

All downloads retain their source bytes: no local resizing, cropping,
re-encoding, trimming, color grading, or generated media was used. The photos
are Wikimedia's existing 1280px JPEG derivatives; the videos and their posters
are the stock provider's existing 720p downloads.
