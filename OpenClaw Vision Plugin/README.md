# Blink Vision — OpenClaw tool plugin

OpenClaw tool plugin, giving the agent `vision_check_camera` — the ability to "peek"
through Blink's camera right now. Communicates with **Vision Agent** (adjacent folder
`Vision Agent/`, FastAPI + OpenCV from Step 1) via HTTP.

This is the part with which we replace the custom Steps 2-3 from `blink-dev-order.md`
(memory, tool use) — OpenClaw takes them over, and this plugin simply connects
our already finished and tested vision layer to it.

## How it works

```
Blink (OpenClaw agent) --tool call--> vision_check_camera
                                                  |
                                                  v
                                    GET http://127.0.0.1:8000/vision/snapshot
                                                  |
                                                  v
                                     Vision Agent (main.py, Step 1)
                                     — captures frame from webcam/CSI-camera,
                                       Haar Cascade + motion detection
```

The agent calls the tool when the user asks "what do you see", "is there anyone
nearby", etc. The tool returns `{ faces_detected, motion_detected,
motion_score, mode }` — the same as what `/vision/snapshot` returns.

## Installation

1. Ensure Vision Agent is running (`Vision Agent/` — `uvicorn main:app`).
2. Build and verify the plugin:

```bash
npm install
npm run plugin:build      # compiles TS -> dist/, generates openclaw.plugin.json
npm run plugin:validate   # verifies manifest with official OpenClaw CLI
npm test
```

3. Install into OpenClaw (from the root of this package):

```bash
openclaw plugins install .
```

4. If needed, specify another Vision Agent baseURL (not `127.0.0.1:8000`) in the
   Gateway plugin config (`~/.openclaw/openclaw.json`):

```json5
{
  plugins: {
    "claude-bot-vision": {
      baseUrl: "http://192.168.1.114:8000",
    },
  },
}
```

5. Restart Gateway — the `vision_check_camera` tool will become available
   to the agent.
